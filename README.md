# 🏦 Bank Loan Analytics Dashboard | Power BI

## 📊 Project Overview

As part of my **Data Analytics Tools in Action** series, I developed an interactive **Bank Loan Analytics Dashboard** using **Microsoft Power BI** to analyze loan applications, borrower behavior, loan performance, repayments, and lending risk.

Using a real-world banking dataset, I transformed raw financial data into actionable insights through KPIs, charts, maps, and interactive visualizations to support data-driven decision-making.

---

# 🎯 Project Objectives

✅ Analyze loan application trends

✅ Monitor funded and received loan amounts

✅ Evaluate portfolio performance

✅ Compare Good Loans vs Bad Loans

✅ Understand borrower characteristics

✅ Analyze loan purposes and customer behavior

✅ Identify repayment and risk patterns

# 📊 Overview Dashboard Analysis

## 📅 Monthly Loan Applications (Line Chart)

### Purpose

Tracks loan application growth throughout the year.

### Key Findings

* Applications increased from **2.3K in January** to **4.3K in December**.
* Consistent growth indicates rising borrowing demand.
* Q4 recorded the highest application volume.

### Business Insight

The increasing trend suggests strong customer demand and potential seasonal borrowing behavior.

---

## 🌎 Loan Applications by State (Map Visualization)

### Purpose

Displays geographical distribution of loan applications across the United States.

### Key Findings

* Applications are distributed across multiple states.
* High-density regions contribute the largest share of applications.
* Enables identification of high-demand lending markets.

### Business Value

Supports regional strategy planning and market expansion opportunities.

---

## ⏳ Loan Applications by Term (Donut Chart)

| Term      | Applications |
| --------- | ------------ |
| 36 Months | 28K (73.2%)  |
| 60 Months | 10K (26.8%)  |

### Insights

* Most customers prefer shorter repayment periods.
* Short-term loans reduce lender risk.
* Faster repayment improves cash flow management.

---

## 🏠 Loan Applications by Home Ownership (Bar Chart)

| Ownership Status | Applications |
| ---------------- | ------------ |

| Own              | 2,838        |

### Insights

* Renters and mortgage holders dominate the borrower population.
* Home ownership can serve as a useful credit-risk indicator.

## 🎯 Loan Applications by Purpose (Treemap)

### Top Loan Purposes

| Purpose            | Applications |
| ------------------ | ------------ |
| Debt Consolidation | 18K          |
| Credit Card        | 5K           |
| Other              | 4K           |
| Home Improvement   | 3K           |
| Major Purchase     | 2K           |

### Insights

* Debt Consolidation is the most common borrowing purpose.
* Credit card refinancing is another major use case.
* Loan purpose analysis helps create targeted lending products.

## 💰 Funded Amount vs Repayment (Clustered Bar Chart)

### Analysis

Compares funded amounts against repayments across different loan statuses.

### Findings

* Fully Paid loans generated the highest repayments.
* Charged-Off loans represent losses.
* Current loans are still under repayment.

### Business Value

Measures portfolio health and repayment efficiency.

# 🔍 Key Business Insights

✔ Most borrowers prefer **36-month loans**.

✔ Loan demand steadily increases throughout the year.

✔ Fully Paid loans dominate the portfolio, indicating strong repayment performance.

✔ Interest Rate and DTI Ratio are useful indicators of borrower risk.
